# tuicr on pvl-a1, pvl-l5, and pvl-x2

On 2026-09-26, the three PVL desktop/primary hosts gained
[`agavra/tuicr`](https://github.com/agavra/tuicr), a code-review TUI with vim
keybindings for reviewing AI-generated diffs.

## Package unit

`pkgs/ext/tuicr/` builds `tuicr` 0.27.0 from the tagged GitHub source with
`rustPlatform.buildRustPackage`, and `pkgs/manifest.nix` exports it as
`pkgs.tuicr` / `nix build .#tuicr`. It is added to `environment.systemPackages`
on `pvl-a1`, `pvl-l5`, and `pvl-x2`.

tuicr is not in nixpkgs. Upstream's own flake uses `naersk.buildPackage` with no
extra build inputs, and every dependency is a crates.io crate pinned in the
committed `Cargo.lock`, so `buildRustPackage` needs no overlay or vendoring
helper. The only extra input is `git` in `nativeBuildInputs`: the upstream test
suite shells out to `git` to build throwaway repositories, and without it about
forty tests fail with `failed to run git: No such file or directory`.

The binary dynamically links only `libgcc_s`, `libm`, and glibc. Clipboard
support uses `arboard` with the Wayland data-control path, so it needs no
external `wl-clipboard`/`xclip` binaries.

## Updates

`pkgs/ext/tuicr/update.sh` reports and updates the version, revision, source
hash, and `cargoHash`, and participates in `scripts/update.sh` as the `tuicr`
`pkgs/ext` unit:

```console
scripts/update.sh --report --only-pkgs-ext
scripts/update.sh --only-pkgs-ext
pkgs/ext/tuicr/update.sh --report
pkgs/ext/tuicr/update.sh --force
```

`cargoHash` is derived by building a staged copy of the unit with a placeholder
hash against the repository's own nixpkgs (via `builtins.getFlake`) and reading
the reported hash, so it always matches the flake build.

## Boundaries

Only the CLI is installed. The bundled agent skill (`skills/tuicr/SKILL.md`) and
any export-target credentials (GitHub/GitLab/etc.) stay user-owned; `tuicr`
reads them from the user's environment and config.

## Validation

```console
nix build .#tuicr --no-link --print-out-paths
nix eval .#nixosConfigurations.pvl-a1.config.system.build.toplevel.drvPath --raw
nix eval .#nixosConfigurations.pvl-l5.config.system.build.toplevel.drvPath --raw
nix eval .#nixosConfigurations.pvl-x2.config.system.build.toplevel.drvPath --raw
pkgs/ext/tuicr/update.sh --report
```

The build runs the upstream test suite with `git` available, and
`<out>/bin/tuicr --version` reports `tuicr 0.27.0`.
