# pvl-x2 Host Network QoS, 2026-07

## Ownership

Incus instance declarations own per-veth rate ceilings. The physical `pvl-x2`
configuration owns aggregate contention on the physical uplink because neither a
guest nor a stack repository can control that bottleneck.

`services.host-network-qos` applies CAKE to `eno1` and an IFB used for received
traffic. It does not replace NetworkManager and does not add qdiscs to Incus
bridges or veths. NetworkManager's dispatcher reapplies the service after an
uplink reconnect.

## Classification

The nftables forward hook assigns traffic from the declared Incus bridges to
DiffServ CS1 and stores that classification in the connection mark. CAKE
`diffserv4` places CS1 in its low-priority Bulk tin. Traffic generated by the
host remains unmarked in Best Effort. Bulk can borrow otherwise-idle capacity,
but host traffic wins when the shaped link is contended.

Upload CAKE uses NAT-aware `dual-srchost` isolation. Download traffic is
redirected through an IFB; the kernel `ctinfo` action restores the saved DSCP
classification before NAT-aware `dual-dsthost` CAKE. `wash` clears the DSCP
after CAKE has selected a tin, so the local policy is not leaked beyond the
shaper.

The conntrack layout follows the `ctinfo` convention:

- `0xfc000000`: six DSCP bits;
- `0x01000000`: classification-present flag;
- `0x21000000`: CS1 plus the flag;
- `0x02ffffff`: mask preserving all connmark bits not owned by this service.

## Initial envelope

Both directions start at `900Mbit`, below the observed 1 Gbit/s physical link.
This is an initial safe envelope, not a claim about ISP capacity. Measure the
sustained end-to-end upload and download rates when the link is otherwise idle,
then keep each configured CAKE bandwidth slightly below its measured bottleneck.
If the real bottleneck is below `900Mbit`, lower the declaration or the upstream
queue will remain outside host control.

The service fails closed to ordinary kernel qdisc defaults: if applying or
verifying the complete CAKE/IFB graph fails, it removes the partial graph. A
disabled or stopped service also removes its qdiscs and IFB. Failure is reported
by the normal systemd unit and never blocks NixOS boot activation.
